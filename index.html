WHAT_IS_CONTEXTUAL

A command-line cockpit for local AI work.

Contextual wraps Ollama in an interactive terminal interface designed for people who want more than a bare chat prompt. Start simple, then progressively use files, retrieval, runtime controls and analytics without leaving the CLI.

>_

CHAT LOCALLY

Use models already installed in Ollama, switch models during a session, customise the system prompt, and toggle supported thinking modes.

[DOC]

TALK TO FILES

Load TXT, Markdown, DOCX, PDF, CSV and XLSX files. Contextual chunks, embeds and retrieves relevant passages for grounded document chat.

HF://

LOAD HF MODELS

Paste an Ollama-compatible Hugging Face model command or reference. Contextual normalises it, pulls it with live progress and switches chat to the new model.

Σ

SEE THE NUMBERS

Inspect session statistics and optional per-response Ollama metrics including TTFT, token counts, evaluation rate and generation speed.

RAG

RETRIEVE, THEN ANSWER

Chonkie recursive chunking, embedding and ChromaDB storage provide context-aware retrieval while preserving natural paragraph and sentence boundaries.

CSV

CLEAN DATA

Use the CSV mode to clean and reformat tabular data into a model-friendly form before analysis.

IMG

GENERATE IMAGES

Launch a platform terminal for local Flux image generation through Ollama, choose dimensions, steps and seed, then import the generated PNGs.

SAVE

KEEP THE SESSION

Export conversations to Markdown or plain text, start a clean session when needed, and keep your workflow outside a browser tab.

START_SIMPLE__GO_DEEPER

Four ways into the machine.

You do not need to understand embeddings or retrieval pipelines to start. Contextual lets newcomers begin with ordinary chat while giving advanced users direct access to RAG, model/runtime tuning and generation workflows.

MODE_01 // CHAT

Local conversation

Pick an installed Ollama model and start prompting. Switch models, change the system prompt, tune runtime settings and save the result.

/switch /prompt /save
MODE_02 // DOCUMENT

Grounded file chat

Load a document, let Contextual create retrievable chunks, then ask questions against the relevant source context instead of the whole file at once.

/file /chunks N
MODE_03 // DATA

CSV preparation

Clean and reshape CSV material for model-friendly analysis, then continue working with it from the same terminal environment.

/csv
MODE_04 // IMAGE

Local generation

Send an image prompt to an Ollama-compatible Flux model with explicit width, height, steps and seed settings.

/set width /set seed

COMMAND_DECK

The useful controls are one slash away.

Contextual exposes common session, model, file and performance controls as readable commands rather than hiding them behind nested settings panels.

/switchChoose another local model or paste an Ollama-compatible Hugging Face model reference.
/fileLoad or switch the document used for grounded chat.
/chunks NControl how many document chunks retrieval supplies to the answer.
/statsDisplay statistics for the current session.
/set verboseToggle per-response Ollama timing and token analytics.
/promptSet a custom system prompt for the current session.
/set cold|balanced|warmApply decoding presets for accuracy, balance or creativity.
/saveExport the conversation to Markdown or plain text.

INSTALL_SEQUENCE

Clone. Set up. Enter the terminal.

Contextual supports macOS, Linux and Windows. Ollama should already be installed and running; the repository setup scripts create the Python environment and install the remaining dependencies.

macOS / Linux

git clone https://github.com/staffordlumsden/Contextual.git
cd Contextual
chmod +x setup.sh
./setup.sh
./run_chatbot.sh

Windows PowerShell

git clone https://github.com/staffordlumsden/Contextual.git
cd Contextual
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup_windows.ps1
.\run_chatbot.ps1
